Connect Gemini by adding your API key to the Phantom V project in Vercel. For security, the key is stored in Vercel—not inside this chat.

  1. Open the Vercel project settings.
  2. Choose Environment Variables.
  3. Add the name GEMINI_API_KEY.
  4. Paste your Google AI Studio key as the value and select Production.
  5. Save, then redeploy the project.
